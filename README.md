# Technologics Studio

## Updated Portfolio Website Prompt

**Create a professional portfolio website for "Technologics" — a full-stack web and app development studio.**

**Positioning & Audience:**
Target audience: business clients across the Middle East and Europe. Clean, modern, corporate aesthetic — deep blues/slate with a single accent color. Simple, RTL-friendly grid layout. Do not mention team size.

**Sections to include:**

1. **Hero Section** — Studio name, tagline (e.g., "Building Digital Experiences That Scale"), CTA button.

2. **Services** — Grid/card layout:
   - Shopify Development & E-commerce Websites
   - Mobile App Development (React Native)
   - Web Development (React.js, Next.js, Angular)
   - Full-Stack Development (MEAN / MERN Stack)
   - .NET Development
   - CRM Application Development
   - Authentication & Authorization Systems
   - Custom Web Application Development

3. **Tech Stack Section** — A visual strip of technology logos/tags:
   - Frontend: React.js, Next.js, Angular, React Native
   - Backend: Node.js, .NET
   - Databases: PostgreSQL, MongoDB
   - Platforms: Shopify

4. **Featured Work / Portfolio** — Gallery grid:
   - **Fameo** — React Native mobile app, tagged "Launching Soon"
   - 4–6 generic placeholder cards for Shopify/e-commerce projects
   - A general "Industry Experience" note (not case-study cards, since these can't be named): mention experience delivering solutions in CRM systems, healthcare/medical applications, and applied sciences platforms — phrased as domain expertise rather than named projects, to respect client confidentiality

5. **About Us** — Paragraph covering full-stack capability across e-commerce, mobile, web apps, CRM, and secure authentication systems — without headcount or client names.

6. **Why Choose Us** — Reliability, technology versatility, cross-industry experience (e-commerce, healthcare, CRM), confidentiality/professionalism with client data, international delivery experience.

7. **Contact Section:**
   - Location: Chennai, India
   - Primary phone: [Add your number]
   - Alternate phone: [Placeholder]
   - Email: technologics@gmail.com (placeholder)
   - Contact form (Name, Email, Message)

8. **Footer** — Studio name, social placeholders, copyright.

**Tone:** Professional, confident, discreet about client specifics but strong on breadth of technical capability.
